# Parser Report v1

`parser_report.json` is generated by `scripts/contracts/generate_output_contract.py` during contract build.

## Purpose

Stabilize HTML -> JSON parsing for preview/review before importer integration.

The parser report tracks:

- section extraction
- question extraction
- asset mapping
- MathML fragment mapping
- question type inference confidence
- parser warnings
- answer summary extraction
- answer reconciliation status/conflicts

## Shape

Top-level fields:

- `schema_version`: `parser_report.v1`
- `artifact_type`: `parser_report`
- `bundle_id`
- `subject`
- `output_mode`
- `summary`
- `confidence_histogram`
- `answer_summary`
- `answer_qa_summary`
- `sections`
- `questions`
- `warnings`
- `timings`

## Summary

`summary` fields:

- `sections_count`
- `question_count`
- `asset_count`
- `math_fragment_count`
- `orphan_asset_count`
- `orphan_math_fragment_count`
- `avg_confidence`
- `min_confidence`
- `unknown_question_type_count`
- `warning_count`
- `answer_issue_count`
- `answer_blocker_count`
- `canonical_answer_missing_count`
- `answer_conflict_count`
- `unresolved_reconciliation_count`

## Confidence Histogram

`confidence_histogram` buckets:

- `ge_0_9`
- `0_75_to_0_9`
- `0_6_to_0_75`
- `lt_0_6`

## Sections

Each section item contains:

- `exam_id`
- `question_count`
- `asset_count`
- `math_fragment_count`
- `warning_count`
- `avg_confidence`
- `question_ids`

## Questions

Each question item contains:

- `item_id`
- `exam_id`
- `question_number`
- `question_type`
- `parse_confidence`
- `warning_codes`
- `asset_count`
- `math_fragment_count`
- `source_location.line`
- `answer_key`
- `answer_sources`
- `reconciliation`
- `answer_detection`
- `rubric_detection`
- `qa_flags`

## Warnings

Each warning item contains:

- `severity`
- `code`
- `message`
- `exam_id`
- `question_id` (empty for section/global warnings)
- `line`

## Timings

`timings` currently includes:

- `parser_json_build_seconds`

`warning_count` tracks non-info parser warnings (`warning|error|blocker` severities).
